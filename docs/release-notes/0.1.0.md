# Form1099Keep 0.1.0

Form1099Keep prepares Forms 1099-NEC and 1099-MISC for small businesses, churches and
other nonprofits, and bookkeepers. Enter your payers and the people you paid (or bring
them over from a MoneyKeep book), answer the checks it asks, then print the recipient
copies and make the files to e-file with the IRS's free IRIS Taxpayer Portal.

Form1099Keep prepares forms. It does not give tax advice and does not send anything to
the IRS.

This is the first public release. Please read [Known limits](../known-limits.md).

## What's in 0.1.0

- **Tax year 2026 forms:** 1099-NEC boxes 1a–1d, 2, 3 and 4, and 1099-MISC boxes 1–15
  with the FATCA check, plus two state lines on each form.
- **2026 thresholds:** $2,000 for 1099-NEC and most 1099-MISC boxes, $10 for royalties
  and substitute payments, $600 for gross proceeds paid to an attorney and for fish
  bought for resale. Any federal tax withheld always needs a form.
- **Checks as plain questions:** missing taxpayer ID numbers or addresses, a missing
  payer phone number, tips without an occupation code, two forms for the same person
  without account numbers, forms below the threshold, and when you have 10 or more
  forms and must e-file.
- **Import from MoneyKeep:** vendors marked for 1099s in a MoneyKeep book, with what
  you paid them (card payments left out). Importing again updates the amounts; forms
  already filed are never changed.
- **Recipient copies:** one PDF with a page for each form and copy (B, 1, 2 and C),
  laid out under IRS Publication 1179. The recipient's ID number shows only its last
  four digits by default.
- **IRIS e-file files:** CSV files for the IRIS Taxpayer Portal, up to 100 forms each.
  Choose the template you downloaded from the portal and the columns are filled in for
  you.
- **Filed and corrected:** mark forms filed with the IRIS receipt number. Filed forms
  are locked until you choose **Correct**.
- **Password protected:** every new 1099 book is encrypted, with a recovery key shown
  once. ID numbers are masked on screen and never written to the history.
- A command-line program, `form1099keep-cli`, for the same jobs.

## Install

### Windows (64-bit)

- **With MoneyKeep Launcher:** install the launcher, then choose **Install** on
  Form1099Keep. It downloads the setup, checks it and runs it. Windows asks for
  administrator permission.
- **From the release:** download `form1099keep-0.1.0-windows-x64-setup.exe` and run it.
  It installs Form1099Keep for all users in `C:\Program Files\Form1099Keep` (Windows
  asks for administrator permission), with a Start menu shortcut and, if you choose, a
  desktop shortcut.

The setup is not signed yet, so Windows SmartScreen may warn: choose **More info**,
then **Run anyway**.

A newer setup updates Form1099Keep in place. When you uninstall it (Settings > Apps >
Installed apps), it asks before deleting your settings; your books are never touched.

### Mac (macOS 11 or later, Apple silicon and Intel)

- **From the release:** download `form1099keep-0.1.0-macos-universal.dmg`, open it and
  drag Form1099Keep to Applications.
- **With MoneyKeep Launcher:** on a Mac the launcher can't install Form1099Keep yet (see
  [Known limits](../known-limits.md)). Install it from the release as above; the
  launcher then finds it, opens it and tells you when a new version is out.

This Mac build is not yet signed with an Apple Developer ID, so macOS warns the first
time you open it. Right-click (or Control-click) Form1099Keep in Applications, then
choose **Open**, and confirm. If macOS doesn't offer **Open**, go to System Settings >
Privacy & Security, scroll down and choose **Open Anyway** next to Form1099Keep. You
only need to do this once.

## Checking your download

Each release has a file called `SHA256SUMS.txt`. It lists a fingerprint (a SHA-256
checksum) for every file in the release. MoneyKeep Launcher checks it for you. To check
a file yourself:

- **Windows:** open PowerShell in the folder with the file and run
  `Get-FileHash .\form1099keep-0.1.0-windows-x64-setup.exe -Algorithm SHA256`
- **Mac:** open Terminal in the folder with the file and run
  `shasum -a 256 form1099keep-0.1.0-macos-universal.dmg`

Compare the long string it prints with the one next to the file's name in
`SHA256SUMS.txt` (capital and small letters count as the same). If they differ, don't
open the file: download it again.
